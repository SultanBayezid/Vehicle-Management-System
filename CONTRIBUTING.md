# Contributing to Vehicle Management System

Thank you for considering contributing.

## How to Contribute

1. Fork the repository and create your branch from `main`.
2. Make your changes with clear, conventional commit messages.
3. Make sure the application still installs cleanly: `composer install`, `npm install && npm run build`, `php artisan migrate --seed`.
4. Follow the existing code style (Laravel conventions, PSR-12).
5. Open a pull request describing what you changed and why.

## Reporting Bugs

Open an issue with:
- Steps to reproduce
- Expected and actual behavior
- PHP / Laravel versions and your environment

## Security Issues

Do not open public issues for security vulnerabilities. Email **sultanbayezidai@gmail.com** instead.

## Code of Conduct

Be respectful and constructive. Keep discussions focused on the code.
